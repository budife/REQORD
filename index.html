WHAT'S NEW

REQORD changelog

Workspace & files
  • New, Load, Save, Save as New, dan draft lokal dengan IndexedDB/localStorage.
  • Nama file aktif tampil di toolbar; Refresh dihapus dari toolbar utama.
  • Save dapat replace workbook dan Save as New membuat workbook baru.
  • Sheet default Sheet1, Sheet 2, dan Sheet 3 dihapus saat Save.
  • Sheet Activity menyimpan history aksi dan dapat dibaca kembali saat Load.
  • Peringatan muncul saat ada perubahan belum disimpan dan halaman di-reload atau ditutup.
  • Template workbook dengan Request List, Ongoing Requests, Done Requests, Daily Tasks, dan Read me.
  • Import/export XLSX, normalisasi tanggal Excel, filter sheet, dan lebar kolom.
Work orders
  • Form Add work order dengan title, requestor, priority, dan request date.
  • Requestor wajib diisi dengan rekomendasi nama, avatar inisial, empty state, dan keyboard navigation.
  • Tiga tabel Request list, Ongoing requests, dan Done requests.
  • Inline editing status dan priority dengan perpindahan tabel otomatis.
  • Target done otomatis tiga hari setelah request date dengan countdown dan indikator urgency.
  • Search title atau requestor.
  • Action Saya kerjain, complete, revisi, dan delete dengan konfirmasi.
  • Done requests dibatasi 10 item per batch dengan Load more done works.
Daily tasks
  • Daily task memakai penyimpanan yang sama dengan request.
  • Kolom memakai label Today dan Done today.
  • Checkbox harian memakai status selesai per tanggal dan otomatis reset setiap hari.
  • Task yang selesai hari ini menampilkan judul strikethrough.
UI & foundation
  • Visual flat minimal dengan palet hijau matcha dan responsive layout.
  • Entrance animation, row transition, hover/focus state, sticky header, shortcut keyboard, smooth scroll, dan reduced-motion support.
  • History & Activity tersedia sebagai panel dari sisi kanan.
  • Footer maker memakai budife.psd dengan modal Profile dan Changelog.
  • Dokumentasi AGENT.md, README.md, STYLE.md, MEMORY.md, ROADMAP.md, dan CHANGELOG.md.
Complete history tersedia di CHANGELOG.md.
